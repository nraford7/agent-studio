# Overlay: Scenario Planning

Overlay id: scenario-planning
Kernel compatibility: 1.0.0

Adapted with attribution from Agent Designer (see `THIRD_PARTY_NOTICES.md`),
rewritten to be **staff-neutral**: the phases below describe work and artifacts,
not people. No phase pre-staffs a persona, and selecting this overlay does not
guarantee that a specialist is required. Any personified role is decided later
through `references/evidence-gate.md`.

Builds external futures to prepare the mind, not to predict. An internal baseline
comes first; external scenarios are reconciled against it at the end.

## Phases

| # | Phase | Work produced | Required artifacts |
|---|---|---|---|
| 0 | Worldview elicitation | Internal baseline captured in plain language before external work | `worldview_model.md` |
| 0b | Context enrichment | Targeted research filling interview gaps | `context_packet.md` |
| 1 | Focal question | An intersection of two uncertainties that creates tension | `focal_question.md` |
| 2 | Predetermined elements | What is locked in, per domain | `predetermined_elements.md` |
| 3 | Critical uncertainties | Parallel-then-converge: isolated identification, then summary-exposed convergence; axes selected from divergence | `critical_uncertainties.md` |
| 4 | Scenario development | Independent sketches → clustered refinement → cross-cluster integration; a stress-test pass | `scenario_N_<name>.md` × 3–4 |
| 5 | Early-warning signals | Observable, leading indicators per scenario | signals sections in scenario files |
| 6 | Impact + strategy | Actor-relative impact, then strategy performance across scenarios | `impact_analysis.md`, `strategy_analysis.md` |
| 7 | Worldview integration | External scenarios reconciled with the internal baseline | `worldview_integration.md` |

## Overlay-specific rules

- The focal question is an intersection of two uncertainties, confirmed by the
  user before phase 2 proceeds.
- `impact_analysis.md` is mandatory between scenarios and strategy — never jump
  from raw scenarios to recommendations.
- The internal baseline is reserved for the final reconciliation, not fed into
  earlier phases.
- Discovery is bounded per kernel rule 10; a stress-test / audit function runs in
  phase 4 (attack plausibility, find too-comfortable scenarios).

## Staffing implication (not a mandate)

Scenario planning **may** justify creative or value-bearing perspectives when
divergent authored worlds materially improve the result — a "Research supports
trying this" family under the evidence gate. It may equally be run entirely
in-house. The overlay states the shape of the work; the gate decides whether any
seat is personified.
